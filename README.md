# BankStatementViewer — Licensing and Usage Terms

> **Status: proposed text for final legal review.** These documents do not by themselves create an active, enforceable license. Do not replace the repository's current license until copyright ownership, release history, and third-party licenses have been reviewed.

## Intended licensing policy

The project owner's intended policy is:

- source code remains publicly viewable on GitHub;
- personal, non-commercial use is free under a separately and validly adopted personal-use license;
- new commercial rights, including commercial sale or distribution, require the owner's written consent and a separate commercial agreement;
- a commercial agreement may combine a fixed upfront fee with a royalty percentage applied to a clearly defined revenue base.

**A public repository does not, by itself, grant permission to use, copy, modify, redistribute, or sell its code.** The final terms must clearly state the exact rights users receive.

## Important notice about the existing license

The repository was found to contain a `LICENSE.txt` file with the GNU Affero General Public License version 3 (AGPL-3.0). These proposed documents do not automatically revoke rights already validly granted under AGPL-3.0. Releases or copies previously received under that license may remain usable under its terms.

Do not place these documents beside the existing license and claim that new restrictions cancel prior AGPL-3.0 rights. Before changing the license for future releases, review ownership of all project materials, contributions, dependencies, and release history. Obtain advice from a lawyer familiar with the relevant jurisdictions where appropriate.

The intended model is **publicly viewable source code under a proprietary license**, which is not necessarily an OSI-approved open-source license.
