# نمایش‌دهنده و فیلتر گردش حساب بانکی

برنامه دسکتاپ WPF با ‎.NET 8‎ برای بازکردن صورت‌حساب‌های بانکی، فیلتر ترکیبی، مشاهده خلاصه، چاپ و خروجی Excel.

## ورودی‌های پشتیبانی‌شده

- **Excel واقعی (`.xls` یا `.xlsx`)** با `ExcelDataReader`
- **فایل متنی بانکی با پسوند `.XLS`** با تشخیص کدگذاری UTF-8، UTF-16، Windows-1256 و Windows-1252 و پشتیبانی از Tab، Pipe، Semicolon و Comma

سرستون‌ها تا حد امکان از روی نامشان شناسایی می‌شوند؛ اگر ساختار فایل قابل تشخیص نباشد، پیام خطا شامل نمونه محتوای خوانده‌شده نمایش داده می‌شود.

## پیش‌نیاز و ساخت

- Windows 10/11
- .NET 8 SDK
- دسترسی به NuGet هنگام اولین Restore

```powershell
dotnet clean
dotnet restore
dotnet build --no-incremental
dotnet run
```

## امکانات

- فیلترهای ترکیبی و دارای تأخیر کوتاه (debounce) برای کاهش پردازش هنگام تایپ
- نرمال‌سازی حروف عربی/فارسی «ي/ی» و «ك/ک»، رقم‌های فارسی/عربی و فاصله‌ها در جستجو
- تعویض گروهی نتیجه‌های فیلتر با یک اعلان به DataGrid، برای کاهش هزینهٔ به‌روزرسانی رابط کاربری
- نمایش ستون‌های تمیزشدهٔ کانال (MOB/PAYA/KYOS/POS)، حساب مقابل، بابت/هدف و نوع ردیف (تراکنش/کارمزد)
- نرمال‌سازی حروف عربی/فارسی، ارقام، علائم ترکیبی و فاصله‌ها برای جستجوی مقاوم‌تر
- امکان نمایش یا پنهان‌کردن ردیف‌های کارمزد؛ مجموع مبلغ و تعداد ردیف‌های کارمزد در خلاصه حفظ می‌شود
- ستون «شرح کامل بانک» برای دسترسی انتخابی به متن اصلی چندخطی، در کنار شرح خلاصه و خواناتر
- خلاصه سریع شامل تعداد تراکنش‌ها و کارمزدها و مبالغ هر کانال و هر روز، به‌علاوهٔ ۲۰ تراکنش بزرگ (بدون ردیف‌های کارمزد)؛ مبلغ تراکنش‌های عادی و کارمزدها جداگانه جمع می‌شوند
- فیلتر با تأخیر ۲۵۰ میلی‌ثانیه و به‌روزرسانی گروهی جدول برای کاهش فشار رابط کاربری
- استفاده از مقدار «مانده از صفحه قبل» در صورت موجودبودن؛ در غیر این صورت محاسبه از نخستین تراکنش
- انتخاب ستون‌های جدول اصلی، چاپ و Excel؛ تنظیمات ستون‌ها و فونت رابط کاربری ذخیره می‌شود
- ستون «توضیحات» تمام خطوط شرح بانک را با حفظ شکست خط نمایش می‌دهد؛ ارتفاع ردیف قابل انتخاب (خودکار/کم/متوسط/زیاد) است و کاربر می‌تواند مرز ردیف را نیز با ماوس تغییر دهد. این انتخاب در تنظیمات ذخیره می‌شود.
- چاپ عمودی و افقی با عرض ستون کنترل‌شده و صفحه‌بندی جداگانه
- خروجی Excel در رشتهٔ کاری پس‌زمینه با نوار پیشرفت؛ ارتفاع ردیف‌ها با تخمین سبک تنظیم می‌شود و برای تک‌تک ردیف‌ها `AdjustToContents` اجرا نمی‌شود
- نمایش نام برنامه‌نویس: شهاب صادقی

## محل تنظیمات

تنظیمات در مسیر زیر ذخیره می‌شوند تا اجرای برنامه از `Program Files` نیازمند دسترسی نوشتن در پوشه نصب نباشد:

`%AppData%\BankStatementViewer\appsettings.json`

در اولین اجرا پس از ارتقا، اگر فایل تنظیمات قدیمی کنار فایل اجرایی باشد و فایل AppData وجود نداشته باشد، برنامه تلاش می‌کند آن را به محل جدید منتقل کند.

## تشخیص و محاسبه کارمزد

ردیف‌هایی که توضیح آن‌ها صراحتاً شامل «کارمزد» است شناسایی می‌شوند. همچنین ردیف بلافاصله بعدی در صورت داشتن شماره پیگیری مشترک (در هر یک از ستون‌های پیگیری/پیگیری واریز)، تاریخ و زمان یکسان، جهت مالی یکسان و مبلغ کمتر از تراکنش قبلی می‌تواند کارمزد شناخته شود. در صورت نبود کانال قابل تشخیص، تطابق شماره پیگیری، تاریخ، زمان و جهت همچنان بررسی می‌شود؛ کانال‌های شناخته‌شدهٔ متناقض باعث رد جفت می‌شوند. این قاعده برای جفت‌های رایج انتقال/کارمزد طراحی شده و بهتر است روی صورت‌حساب بانک‌های جدید نیز نمونه‌گیری شود.

## محدودیت آزمون

در محیط توسعهٔ این بسته ‎.NET SDK‎ نصب نیست؛ بنابراین باید `dotnet restore` و `dotnet build --no-incremental` روی ویندوز اجرا شوند. بعد از کامپایل، خروجی کارمزد و مانده آغازین را با صورت‌حساب رسمی بانک تطبیق دهید، به‌خصوص برای بانک‌هایی که ساختار سطرهای کارمزد یا «مانده از صفحه قبل» متفاوت است.
